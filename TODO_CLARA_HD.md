  patch is reported broken; everything else applies.
- `nicoverbruggen/kobopatch-webui` **v1.63** bundles 4.38.23828 patches and patches
  **client-side in a browser** (no CLI/headless mode).

**Recommended route (safest):** use the browser tool `kp.nicoverbruggen.be`
→ pick Clara HD + 4.38.23828 + patches → it produces a patched `KoboRoot.tgz` →
drop into `.kobo/` → eject → reboot installs it. Keep stock firmware as restore point.

**Hard rules:**
- Back up first. A bad `libnickel` patch soft-bricks (boot loop → factory/recovery).
- Only patch with a set matching **exactly 4.38.23828**.
- A firmware UPDATE later disables KFMon → rerun the one-click installer.

**Wanted patches:** telemetry off · store/Discover/ad nags off · stock-reader
typography unlock · refresh/night tweaks. (Most are redundant since KOReader is
the main reader — main unique win is privacy/telemetry.)

## 6. Gotchas & hard-won learnings (READ before touching things)

- **USB volume drops mid-operation** — happened repeatedly on this device. Always
  `cp … && sync && sync` in a *single* command; don't let the device idle. If the
  copy is interrupted after an `rm`, the plugin dir is left missing — recopy.
  **Don't launch KOReader until a copy fully finishes.** SSH (wireless) avoids this.
- **macOS USB copies litter the vfat with `._*` AppleDouble files** (one per
  `.lua`, found next to v0.3). KOReader ignores them but they are junk;
  `scripts/deploy.sh` (scp) doesn't create them and replaces the whole folder.
- **KOReader's SSH menu options are greyed out while the server runs** — stop it
  before toggling key-only / passwordless / port. The server is KOReader's
  patched dropbear: `-s` = key-only; `-n` ("Login without password") accepts
  *any* password but the client must still attempt password auth, so
  `BatchMode=yes` can't use that window — use `expect` or type Enter at the
  prompt. `authorized_keys` is read from `settings/SSH/` (vfat perms ignored).
  Restarting KOReader does not autostart SSH (by design, §7) — start it again.
- **Standard Ebooks is anti-scraping** — its `/downloads/*.epub` links are
  **honeypots** ("following this link will ban your IP for 24 hours"). Scraping
  risks banning the user's HOME IP. OPDS feed is patron-auth-gated. → only ever
  use SE via **authenticated OPDS + token**, never scraping.
- **Feedbooks** killed its free public-domain OPDS; `catalog.feedbooks.com` is the
  commercial store (sample/paid links only). Not usable as a free source.
- **DOAB / OAPEN** block **datacenter IPs** (403 "address not allowed") but work
  from residential IPs (the Kobo). Can't be tested from a cloud/datacenter host.
- **Plugin modules share ONE flat `require` namespace with KOReader core and all
  other plugins.** The loader puts the plugin dir first on `package.path`, but
  `package.loaded` wins: KOReader loads its own `frontend/version.lua` before
  any plugin, so OpenShelf's `version.lua` was never read and v0.4 died at load
  (`http_util.lua:17: attempt to concatenate local 'VERSION' (a table value)` in
  `crash.log`; the plugin simply vanishes from the menu). Reserved names are in
  `test/unit.lua`; when in doubt prefix new modules `openshelf_`. Also: the
  `name` field in `_meta.lua` is deprecated (loader warns, uses the folder name).
- **Lua version mismatch**: device KOReader runs **LuaJIT (Lua 5.1 semantics)**;
  local tests *used to* run **Lua 5.5**. Caught a real bug: `require()` returns a
  *second* value (loader path) on 5.3+; in the last slot of a table constructor it
  leaks in. Fix: bind requires to locals first (see `catalog.lua`). Since
  2026-10-25 every local check runs under **LuaJIT** too (rocks installed with
  `luarocks --lua-version=5.1`) — keep it that way.
- **NickelMenu**: `:` is the field separator — **labels must not contain colons**
  (a `Wi-Fi: Toggle` label broke parsing → "unknown action"). Format:
  `menu_item : location : label : action : arg` (exactly 4 colons).
- **Variable fonts** (Literata, EB Garamond) render plainly in stock Nickel but
  fine in KOReader. Atkinson Hyperlegible is static (4 weights) → perfect everywhere.
- **settings.reader.lua** was pre-seeded before first launch; KOReader merges and
  rewrites it on exit, preserving the seeded keys.
- **KOReader base `Menu` is text-only** — no per-item images. Cover thumbnails
  required a custom widget (`coverbrowser.lua`), rendering downloaded bytes via
  `RenderImage:renderImageData(data, #data, false)` → fit → `ImageWidget{image=bb}`.
- **`renderImageData(..., w, h)` STRETCHES to exactly w×h** (so does
  `Mupdf.renderImage`) — no aspect fit. Decode at native size and scale once with
  `RenderImage:scaleBlitBuffer` (frees the original by default). See `covers.lua`.
- **Plain `ltn12` sinks ignore socketutil's total timeout** — LuaSocket resets its
  timer on every chunk. Use `socketutil.table_sink` / `file_sink` (wall-clock
  limit) and create them *after* `socketutil:set_timeout(...)`.
- **`%w` / `%a` are ASCII-only in LuaJIT** (C locale): `gsub("[^%w%s]", " ")`
  shreds UTF-8 ("Misérables" → "mis rables"). Keep bytes ≥128: `[%w%s\128-\255]`.
- **Replaced widget subtrees are never freed** — `UIManager:close` only sends
  `CloseWidget` to the tree that is current at close time. Call `old:free()`
  before swapping `self[1]` (see `CoverBrowser:_render`).
- **Lucene specials in user text break Internet Archive search** — a `:` or `(`
  makes advancedsearch return an error (seen as zero results). Strip them and
  lowercase (`AND`/`OR`/`NOT` are operators) — `InternetArchive.sanitizeQuery`.
- **`_` as a loop variable shadows gettext** — `for _, x in ipairs(…)` inside a
  file with `local _ = require("gettext")` makes the next `_("…")` call a number
  call. Use `__` / `___` (luacheck's `21[1-3]/_.*` ignore hides it).
- **KOReader's bundled JSON decodes `null` as a function** (LuaJSON sentinel), so
  `item.name or "x"` keeps the function. `Entry.download` coerces non-strings.
- **Forked subprocesses die on the macOS emulator** the moment they use the
  network (same fork + HTTPS works in a bare luajit; it's the Cocoa/SDL process).
  `jobs.lua` runs inline there automatically. Linux devices are unaffected —
  KOReader's own newsdownloader/OPDS use the same `runInSubProcess`.
- **`screencapture` is refused for the terminal on this Mac** — review emulator
  screens with `Screen:shot(path)` from a dev script (`OPENSHELF_DEV_SCRIPT`).
- **KOReader's own `kodev` needs `wget` and bash ≥4** — neither is in its macOS
  package list; `brew install wget` and put Homebrew bash first on PATH.
- **`FrameContainer{width=,height=}` doesn't size the frame** — size the child
  with an exact `dimen` (`LeftContainer`/`CenterContainer`) and add border +
  padding yourself; `getSize()` is content + border + padding.
- **Firmware updates disable KFMon** → the KOReader launcher icon vanishes; rerun
  the one-click installer to restore (books/settings survive).
- **KFMon reads its config only at boot / after a USB session** — a new
  `.adds/kfmon/config/*.ini` (the OpenShelf launcher) needs a reboot. NickelMenu's
  `generator : main : kfmon` then lists the watch by its `label`, no NM config
  edit needed, and launches it over KFMon's IPC even if the icon was never indexed.
- **DOAB / OAPEN REST search is IP-allowlisted** — `…/rest/search` answers
  `403 "You address is not allowed to access this API."` from the Kobo, the Mac and
  any User-Agent (probed 2026-10-26; `library.oapen.org/rest` identical; the DSpace 7
  `/server/api` path is 404). Only OAI-PMH (`/oai/request`, harvesting, no search) is
  open. Options: ask DOAB for allowlisting (no — IPs change), harvest OAI-PMH into a
  local index (heavy), or drop/replace the source. Decide before the next release.
- **Nickel imports new files only after a USB session** — a reboot does NOT index
  a new PNG (confirmed 2026-10-26: the launcher icon stayed out of the library) and
  neither does leaving KOReader, so Wi-Fi downloads don't show in the stock library
  either. NickelMenu `nickel_misc : rescan_books_full` fakes a connect/disconnect
  cycle; `kobo/nm/openshelf-import` adds it as "Import books". A fresh icon may stay
  "processing" for KFMon's own tap path until the next boot (thumbnail cache).
- **KOReader rebuilds the file manager, and re-runs every plugin's `init()`, after
  each book** — `init()` runs several times per process. Anything that must happen
  once (the `OPENSHELF_DEV_SCRIPT` hook) needs a module-level guard; the home-mode
  auto-open relies on exactly this rebuild.
- **The self-updater must never run against the emulator's symlinked plugin**
  — renaming the link would move the dev checkout out of the plugins dir. It
  refuses a symlinked plugin folder; test with `scripts/emu.sh --home DIR
  --copy`. Its own folder comes from `debug.getinfo` (the loader's plugin
  path), so nothing hardcodes `/mnt/onboard/.adds/koreader/plugins`.
  Siblings named `*.koplugin.old` / `*.koplugin.staging` are ignored by
  KOReader's loader (it only loads names ending in `.koplugin`).
- **The emulator boots into the quickstart guide** until `quickstart_shown_version`
  in `.kohome/settings.reader.lua` is ≥ KOReader's force-show version (a from-source
  build normalizes to 0, so set it huge). Until then the file manager never shows
  and file-manager-context plugin code doesn't run.

## 7. Design decisions (from grilling — don't relitigate)

- **DRM is a hard boundary.** Never strip Adobe DRM. Library/purchase (DRM'd)
  books stay in the **stock Kobo reader**; OpenShelf only ever handles DRM-free files.
- **No self-hosting.** OpenShelf *is* the content strategy (no Wallabag/Syncthing/
  Calibre-Web). Everything in one app.
- **OpenShelf = free/DRM-free downloads today**, with a **pluggable result model**
  so borrow/buy slot in later with no UI rewrite.
- **Dedupe + prefer-best-edition**; **keep the results list** (don't auto-pick);
  **group by action**.
- **Covers ON by default**, with a toggle fallback to text.
- **Downloads go to a visible top-level folder** (`/mnt/onboard/OpenShelf`), not
  KOReader's hidden data dir, so books show in both readers (decided 2026-10-25).
- Access to device: **SSH, on-demand, key-only** (not always-on).
- Scope: software + firmware now; hardware later.
- **v0.5 UI redesign (grilled 2026-10-26, 36 decisions): see `DESIGN.md`.**
  Headlines: native chrome + custom results/detail/shelves; home screen opens
  directly; results survive; tap = detail, hold = download; subprocess for
  search/download/covers; own library JSON + KOReader Collection "OpenShelf";
  no emoji (KOReader has no emoji font — Nerd Font glyphs instead); covers
  always on (text-only fallback removed); single release via the emulator.
